### 🟢 EASY (1-2 ชม.)
- **ชื่อ:** **MealPrepTimer CLI** — "AI Meal Prep Orchestrator สำหรับ WFH dev"
- **Problem:** dev ที่จะ meal prep มักไม่รู้ว่าจะทำอะไรพร้อมกันยังไงให้เสร็จใน 1 ชั่วโมง — ต้มข้าวพร้อมอบไก่พร้อมซอยผักพร้อมกันอย่างไรให้ไม่มีอะไรไหม้
- **Stack:** Python 3.12 + Claude API (`claude-haiku-4-5-20251001`) + `rich` library terminal UI
- **Core logic:**
```python
import anthropic
from rich.console import Console
from rich.table import Table

def gen_meal_plan(ingredients: list[str], time_minutes: int = 60) -> str:
    client = anthropic.Anthropic()
    msg = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=1024,
        messages=[{"role": "user", "content":
            f"วัตถุดิบที่มี: {', '.join(ingredients)}\n"
            f"เวลา: {time_minutes} นาที\n"
            "สร้าง meal prep timeline แบบ parallel cooking — บอกว่าทำอะไรตอนไหนพร้อมกัน "
            "เพื่อให้ทุกอย่างเสร็จพร้อมกันใน 60 นาที\n"
            "format: markdown table คอลัมน์ เวลา | กิจกรรม | หมายเหตุ ภาษาไทย"
        }]
    )
    return msg.content[0].text

ingredients = ["ไก่ 500g", "ข้าวสวย 3 ถ้วย", "บรอคโคลี", "แครอท", "ไข่ 6 ฟอง"]
console = Console()
console.print("[bold green]🥗 AI Meal Prep Planner[/bold green]")
console.print(gen_meal_plan(ingredients))
```
