### 🟢 EASY (1-2 ชม.)

- **ชื่อ:** **PetNameBot** — ตัวช่วยตั้งชื่อสัตว์เลี้ยงสุดน่ารักด้วย AI
- **Problem:** เจ้าของแมว-หมาใหม่มักไม่รู้จะตั้งชื่อยังไงให้น่ารัก มีความหมาย และ unique — ปัญหาเล็กแต่ viral บน TikTok มาก
- **Stack:** Python 3.12 + `anthropic` SDK + `click` CLI library — รันใน terminal, output ไม่ต้องมี UI
- **ทำไมขายได้:** เอา screen record ขณะรัน CLI แล้วโพสต์ TikTok — "AI ตั้งชื่อแมวให้ฉัน" ได้ view เยอะมาก → ใส่ affiliate link smart pet feeder ใน bio → passive income

**Code sample (เริ่มได้เลย 30 นาที):**
```python
# pet_name_bot.py
import anthropic, click

@click.command()
@click.option('--breed', prompt='สายพันธุ์สัตว์เลี้ยง', help='เช่น Scottish Fold, Golden Retriever')
@click.option('--gender', prompt='เพศ (ผู้/เมีย)', help='ผู้ หรือ เมีย')
@click.option('--personality', prompt='นิสัย (เช่น: ซน ขี้เล่น เงียบ)', default='ซน')
@click.option('--count', default=5, help='จำนวนชื่อที่ต้องการ')
def suggest_names(breed, gender, personality, count):
    """🐾 PetNameBot — AI ตั้งชื่อสัตว์เลี้ยงภาษาไทย"""
    client = anthropic.Anthropic()
    prompt = f"""คุณเป็นผู้เชี่ยวชาญตั้งชื่อสัตว์เลี้ยง ช่วยแนะนำ {count} ชื่อสำหรับ:
สายพันธุ์: {breed} | เพศ: {gender} | นิสัย: {personality}

สำหรับแต่ละชื่อให้มี: ชื่อ (ไทย+อังกฤษ) | ความหมาย | เหตุผลที่เหมาะ
Format: 1. 🐾 ชื่อ — ความหมาย — เหตุผล"""
    
    message = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=512,
        messages=[{"role": "user", "content": prompt}]
    )
    click.echo(f"\n✨ ชื่อแนะนำสำหรับ {breed} {gender} นิสัย{personality}:\n")
    click.echo(message.content[0].text)

if __name__ == '__main__':
    suggest_names()
```

**Action:** `pip install anthropic click` → copy code → รัน → screen record → TikTok ✅
