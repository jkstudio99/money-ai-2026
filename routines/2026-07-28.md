## 🛠️ PART 2: Daily Coding Project (3 ระดับ)

### 🟢 EASY (1-2 ชม.)

- **ชื่อ:** `ResumeBoost CLI` — AI Resume Bullet-Point Rewriter สำหรับ dev ไทย
- **Problem:** dev ไทยเขียน resume bullet point แบบ "ทำ feature X" แต่ ATS และ recruiter ชอบ "Reduced API response time by 65% by implementing Redis caching, serving 50K daily active users" — ต่างกันมาก
- **Stack:** Python 3.12 + `anthropic` SDK + `typer` CLI + `rich` table output; ไม่ต้องมี backend
- **Code เริ่มต้น (ทำได้เลยใน 60 นาที):**

```python
import anthropic, typer
from rich.console import Console
from rich.table import Table

app = typer.Typer()
console = Console()
client = anthropic.Anthropic()

SYSTEM = """คุณเป็น technical recruiter ระดับ Senior ที่เชี่ยวชาญ ATS optimization.
รับ resume bullet point ภาษาไทยหรือ English → rewrite เป็น format:
[Action verb] + [Task/Feature] + [Tech used] + [Quantified result]
ถ้าไม่มี metric ให้ suggest placeholder เช่น "[X%]" พร้อม hint ว่าหาจากไหน.
ตอบเป็น JSON: {"original": "...", "rewritten": "...", "why": "..."}"""

@app.command()
def boost(bullet: str = typer.Argument(..., help="Paste your resume bullet point")):
    """Rewrite a resume bullet point to be ATS-friendly and quantified."""
    response = client.messages.create(
        model="claude-sonnet-5",
        max_tokens=512,
        system=SYSTEM,
        messages=[{"role": "user", "content": bullet}]
    )
    import json
    result = json.loads(response.content[0].text)
    table = Table(title="Resume Boost Result", show_lines=True)
    table.add_column("Before", style="red", width=40)
    table.add_column("After", style="green", width=40)
    table.add_row(result["original"], result["rewritten"])
    console.print(table)
    console.print(f"\n[bold yellow]Why:[/bold yellow] {result['why']}")

if __name__ == "__main__":
    app()
```

- **Run:** `pip install anthropic typer rich && python resume_boost.py "ทำ feature login ด้วย JWT"`
- **ทำไมขายได้:** Thailand developer shortage 80K คน → บริษัทจ้างเยอะ → dev ทุกคนต้องการ resume ที่ดีขึ้น; monetize: ฟรี CLI → upsell DevCoach TH Pro ฿199/เดือน; alternative: ขาย template prompt pack ฿290 ใน Gumroad
