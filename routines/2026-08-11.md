## 🛠️ PART 2: Daily Coding Project (3 ระดับ)

### 🟢 EASY (1-2 ชม.)

- **ชื่อ:** **ConvertBot CLI** — Thai Freelancer Currency + WHT Tax Calculator
- **Problem:** freelancer ไทยต้องคำนวณ USD→THB + WHT 3% ทุกครั้งที่ออก invoice — ทำเองผิดบ่อย เสียเวลา ไม่มี tool ง่ายๆ ที่ทำครบใน command เดียว
- **Stack:** Python 3.12 + `httpx` (FX rate จาก open.er-api.com ฟรี) + `rich` library (pretty table) — ไม่มี API key ไม่มีค่าใช้จ่าย

```python
import httpx, sys
from rich.table import Table
from rich.console import Console

BASE_RATES_URL = "https://open.er-api.com/v6/latest/USD"
console = Console()

def get_rate(from_cur: str = "USD", to_cur: str = "THB") -> float:
    r = httpx.get(f"https://open.er-api.com/v6/latest/{from_cur.upper()}", timeout=5).json()
    return r["rates"].get(to_cur.upper(), 1.0)

def invoice_calc(amount: float, from_cur: str = "USD", wht: bool = True):
    rate = get_rate(from_cur, "THB")
    thb = amount * rate
    wht_amount = thb * 0.03 if wht else 0
    net = thb - wht_amount

    t = Table(title=f"Invoice: {amount:,.2f} {from_cur.upper()} → THB", style="bold cyan")
    t.add_column("รายการ", style="white", min_width=28)
    t.add_column("จำนวน", justify="right", style="green")
    t.add_row(f"{from_cur.upper()}/THB Rate (live)", f"฿{rate:,.4f}")
    t.add_row(f"Gross Amount (THB)", f"฿{thb:,.2f}")
    if wht:
        t.add_row("หัก WHT 3%", f"- ฿{wht_amount:,.2f}")
    t.add_row("[bold]Net ที่ได้รับจริง[/bold]", f"[bold green]฿{net:,.2f}[/bold green]")
    console.print(t)
    console.print("\n[yellow]💡 Tip:[/] ขอ WHT Certificate จาก client ไทยทุกครั้ง → ใช้ยื่น ภ.ง.ด.90 ปลายปี\n")

if __name__ == "__main__":
    amount = float(sys.argv[1]) if len(sys.argv) > 1 else 1000.0
    cur = next((a.upper() for a in sys.argv[2:] if a.upper() in ("USD","EUR","GBP","JPY")), "USD")
    no_wht = "--no-wht" in sys.argv
    invoice_calc(amount, cur, wht=not no_wht)
```

**Usage:** `python convertbot.py 2500 USD` → ได้ table THB + WHT ทันที | `python convertbot.py 1500 EUR --no-wht` → ไม่หัก WHT

- **ทำไมขายได้:** freelancer ไทยหลายแสนคนต้องการ tool นี้ทุกครั้งที่ออก invoice; publish GitHub ฟรี → viral ใน Facebook Group Freelancer Thailand → ต่อยอดเป็น FreelancePay.th web app
