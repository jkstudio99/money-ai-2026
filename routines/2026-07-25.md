## 🛠️ PART 2: Daily Coding Project (3 ระดับ)

### 🟢 EASY (1-2 ชม.)
- **ชื่อ:** `SunRoute CLI` — AI Travel Planner + UV Safety Warning
- **Problem:** นักท่องเที่ยวไทยและ digital nomad ต้องการ itinerary ที่รวม weather + UV + activity ในคำสั่งเดียว
- **Stack:** Python 3.12 + `anthropic` SDK (`claude-haiku-4-5`) + Open-Meteo API (ฟรี UV index + weather) + Rich library (pretty terminal output)
- **วิธีทำ:**
  ```bash
  pip install anthropic httpx rich
  ```
  ```python
  import anthropic, httpx
  from rich.console import Console

  console = Console()
  client = anthropic.Anthropic()

  def get_uv_and_weather(lat: float, lon: float) -> dict:
      resp = httpx.get(
          "https://api.open-meteo.com/v1/forecast",
          params={"latitude": lat, "longitude": lon,
                  "daily": "uv_index_max,precipitation_sum",
                  "timezone": "Asia/Bangkok", "forecast_days": 3}
      )
      return resp.json()

  def generate_itinerary(city: str, days: int, weather: dict) -> str:
      uv_avg = sum(weather["daily"]["uv_index_max"][:days]) / days
      message = client.messages.create(
          model="claude-haiku-4-5-20251001",
          max_tokens=1024,
          messages=[{
              "role": "user",
              "content": f"สร้าง itinerary ท่องเที่ยว {city} {days} วัน ภาษาไทย "
                         f"UV index เฉลี่ย {uv_avg:.1f} — แนะนำช่วงเวลาออกนอกบ้านที่เหมาะสม "
                         f"และ SPF ที่ควรใช้ ให้ actionable มาก"
          }]
      )
      return message.content[0].text

  if __name__ == "__main__":
      city = "เชียงใหม่"
      lat, lon = 18.7883, 98.9853
      weather = get_uv_and_weather(lat, lon)
      console.print(f"[bold cyan]☀️ UV Index (3 วัน): {weather['daily']['uv_index_max']}[/bold cyan]")
      itinerary = generate_itinerary(city, 3, weather)
      console.print(itinerary)
  ```
- **ทำไมขายได้:** demo ง่าย, ผลลัพธ์น่าประทับใจ, post TikTok ได้ทันที; ขยายเป็น LINE bot ในขั้นต่อไปได้
