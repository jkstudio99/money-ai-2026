### 🟢 EASY (1-2 ชม.) — PetCare CLI

- **ชื่อ:** **PetCare CLI** — "ตารางดูแลน้อง ครบในคำสั่งเดียว"
- **Problem:** เจ้าของสัตว์เลี้ยงไทยต้องจำตารางกิน/ยา/วัคซีนเอง — ลืมบ่อย ไม่มี tool ง่ายๆ ที่ gen ตารางสรุปออกมาพร้อมใช้
- **Stack:** Python 3.12 + Claude API (`claude-haiku-4-5-20251001`) + `rich` library (pretty console output)

```python
# usage: python petcare.py --name "มิโล" --breed "golden retriever" --age 2 --weight 28
import anthropic, argparse
from rich.console import Console

def gen_schedule(name, breed, age, weight):
    client = anthropic.Anthropic()
    msg = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=1024,
        messages=[{"role": "user", "content":
            f"สร้างตารางดูแล {breed} ชื่อ {name} อายุ {age} ปี น้ำหนัก {weight}kg\n"
            "รวม: เวลาให้อาหาร (ปริมาณ), ออกกำลัง, ยา/วิตามิน, อาบน้ำ, "
            "วัคซีนตามอายุ, breed-specific health tips — format: markdown table ภาษาไทย"
        }]
    )
    return msg.content[0].text

parser = argparse.ArgumentParser()
parser.add_argument("--name"), parser.add_argument("--breed")
parser.add_argument("--age", type=int), parser.add_argument("--weight", type=float)
args = parser.parse_args()
Console().print(gen_schedule(args.name, args.breed, args.age, args.weight))
```

- **ทำไมขายได้:** GitHub repo ฟรี → viral ใน dev + pet community → "PetCare Plus" API subscription ฿99/เดือน: LINE Notify reminder + vet appointment tracker + weight log chart
