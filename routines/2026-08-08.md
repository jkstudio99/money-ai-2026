### 🟢 EASY (1-2 ชม.)

- **ชื่อ:** **"CoffeeDev CLI"** — Pomodoro timer ที่รู้จัก brew method ของกาแฟคุณ
- **Problem:** dev ส่วนใหญ่ต้องการ Pomodoro timer ธรรมดาใน terminal แต่ไม่มีใคร integrate เข้ากับ "coffee break ritual" ที่ WFH dev ทำทุกวัน — CoffeeDev: ครบ 25 นาที → CLI บอกให้ brew กาแฟ method ที่เหมาะกับ break time (5 นาที = espresso / 10 นาที = AeroPress / 15 นาที = V60 pour-over)
- **Stack:** Python 3.12 + `rich` (live progress bar) + `time` standard library — ไม่ต้องมี external API ใดๆ เลย (cost ฿0)
- **ทำไมขายได้:** demo บน GitHub ฟรี → viral ในกลุ่ม dev + coffee lover (two audiences overlap ดีมาก) → share ง่าย เพราะ fun + useful; ต่อยอดเป็น desktop app (Electron) หรือ web app → Pro version ฿99 lifetime deal

**Code sketch (เขียนได้ใน 30 นาที):**
```python
# coffeedev.py
from rich.progress import track
from rich.console import Console
from rich.panel import Panel
import time, sys

BREW_GUIDE = {
    "work":  "⏱️  Focus mode เริ่มแล้ว — ปิด Slack, เปิด editor, ห้ามดู TikTok",
    "short": "☕ Short break (5 นาที) — แนะนำ: espresso หรือดื่มน้ำ 1 แก้ว",
    "long":  "☕ Long break (15 นาที) — แนะนำ: AeroPress 2:30 นาที / V60 pour-over 3:00 นาที",
}

console = Console()

def run(minutes: int, label: str):
    console.print(Panel(BREW_GUIDE[label], style="bold cyan"))
    for _ in track(range(minutes * 60), description=f"[green]{label.upper()} — {minutes} min"):
        time.sleep(1)
    console.print(Panel("🔔 หมดเวลา! ถึงเวลาพักแล้ว ☕", style="bold yellow"))

def pomodoro(cycles=4):
    for i in range(cycles):
        console.rule(f"[bold]Cycle {i+1}/{cycles}")
        run(25, "work")
        run(5 if (i + 1) % 4 != 0 else 15,
            "short" if (i + 1) % 4 != 0 else "long")

if __name__ == "__main__":
    cycles = int(sys.argv[1]) if len(sys.argv) > 1 else 4
    pomodoro(cycles)
```
