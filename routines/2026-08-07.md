- **Problem:** developer ไทยมักส่ง prompt ใหญ่ๆ ไป Claude/GPT โดยไม่รู้ว่าแต่ละ request เสียเงินเท่าไหร่ — จนถึงสิ้นเดือนตกใจกับ bill
- **Stack:** Python 3.12 + `tiktoken` (token counting) + `rich` library (pretty table) + hardcoded pricing JSON (อัปเดตมือ weekly)
- **วิธีใช้:**
  ```bash
  python promptcost.py --model "claude-sonnet-5" --prompt "เขียน React component นี้ให้ใหม่..."
  # → output:
  # ┌─────────────────────────────────────────────────────────┐
  # │ Model: claude-sonnet-5  | Tokens: 847 input             │
  # │ Input cost:  $0.0025    | Output est (500 tok): $0.0075 │
  # │ Total est:   $0.0100    | THB est: ฿0.35                │
  # │ 1,000 calls/mo: $10.00  | 10K calls/mo: $100.00         │
  # └─────────────────────────────────────────────────────────┘
  ```
  add flag `--compare` → แสดง top-5 model ราคาถูกกว่าสำหรับ prompt ขนาดนี้
- **ทำไมขายได้:** developer ทุกคนต้องการ tool นี้ก่อน scale ไปจริง; โพสต์บน GitHub ฟรี → viral ใน dev community → upgrade เป็น TokenBudget.dev (web version) Pro
