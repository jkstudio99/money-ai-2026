## 🛠️ PART 2: Daily Coding Project (3 ระดับ)

### 🟢 EASY (1-2 ชม.)

- **ชื่อ:** **"EcoSwap CLI"** — AI แนะนำทางเลือก eco-friendly แทนสินค้าที่ใช้ประจำ
- **Problem:** คนอยากเปลี่ยนไปใช้ของ eco แต่ไม่รู้จะเริ่มจากอะไร — ต้อง research เอง เสียเวลา
- **Stack:** Python 40 บรรทัด + Claude API (`claude-haiku-4-5`) รับ input ชื่อสินค้า (เช่น "ขวดน้ำพลาสติก", "ถุงพลาสติก") → gen eco alternative + เหตุผล + ราคาเทียบ + keyword ค้นหา Shopee → output markdown พร้อมใช้

```python
import anthropic, sys

client = anthropic.Anthropic()

def eco_swap(product: str) -> str:
    msg = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=512,
        messages=[{
            "role": "user",
            "content": f"แนะนำทางเลือก eco-friendly แทน '{product}' — ระบุ: ชื่อสินค้า, เหตุผลดีกว่า, ประหยัดเงินต่อปีประมาณ, ราคา Shopee โดยประมาณ, keyword ค้นหา Shopee — format markdown table"
        }]
    )
    return msg.content[0].text

if __name__ == "__main__":
    product = " ".join(sys.argv[1:]) or "ขวดน้ำพลาสติก"
    print(eco_swap(product))
```

- **ทำไมขายได้:** publish เป็น PyPI package ฟรี + README ที่มี affiliate link Shopee eco → viral ใน dev community ไทย → passive affiliate income จาก organic traffic
