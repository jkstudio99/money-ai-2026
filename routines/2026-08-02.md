**Code sample:**
```python
# vocab_flash.py
import anthropic, click
from rich.panel import Panel
from rich.console import Console
from rich.markdown import Markdown

console = Console()
client = anthropic.Anthropic()

@click.command()
@click.argument("term")
@click.option("--quiz", is_flag=True, default=True, help="แสดง quiz 3 ข้อ")
def flash(term, quiz):
    """🧠 VocabFlash — AI อธิบาย tech term ภาษาไทย + code example + quiz"""
    prompt = f"""อธิบาย "{term}" สำหรับ developer ไทย ด้วยรูปแบบนี้:

## 🔤 {term}
**คำอธิบายสั้น (1-2 ประโยค ภาษาไทย):**

**Analogy ที่เข้าใจง่ายแบบชีวิตจริง:**

**ตัวอย่าง code (Python หรือ JavaScript):**
```python
# code ที่ชัดเจน ไม่เกิน 10 บรรทัด
```

**❓ Quiz 3 ข้อ (คำถามสั้นๆ พร้อมเฉลยท้าย):**
1. ...
2. ...
3. ...

**✅ เฉลย:** ..."""

    with console.status(f"[cyan]กำลังอธิบาย '{term}'...[/cyan]"):
        response = client.messages.create(
            model="claude-haiku-4-5-20251001",
            max_tokens=800,
            messages=[{"role": "user", "content": prompt}]
        )
    console.print(Panel(
        Markdown(response.content[0].text),
        title=f"[bold cyan]🧠 VocabFlash: {term}[/bold cyan]",
        border_style="cyan"
    ))

if __name__ == "__main__":
    flash()
```
