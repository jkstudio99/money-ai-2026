### 🟢 EASY (1-2 ชม.)

- **ชื่อ:** `ShopeeRefill Scout` — Shopee Sustainable Beauty Price Tracker
- **Problem:** ผู้ซื้อหาของ refillable/sustainable บน Shopee ยาก เพราะ search keyword กระจัดกระจาย (refillable, zero-waste, eco-friendly) และราคาเปลี่ยนทุกวัน
- **Stack:** Python 3.12 + `httpx` + `beautifulsoup4` + Claude API (สรุป + เปรียบเทียบ) + `rich` สำหรับ terminal output สวยงาม
- **ทำไมขายได้:** ส่ง daily email digest ให้ subscriber 500 คน → ขาย affiliate link embed; หรือ monetize เป็น Chrome extension ฿99/ปี; ใช้เวลา build แค่ 90 นาที แต่ passive income ได้จริง

```python
# core flow
import httpx, anthropic
from bs4 import BeautifulSoup

KEYWORDS = ["refillable skincare", "zero waste beauty", "modular bottle"]

async def search_shopee(keyword: str) -> list[dict]:
    # hit Shopee search API (public endpoint)
    url = f"https://shopee.co.th/api/v4/search/search_items?keyword={keyword}&limit=20"
    r = await httpx.AsyncClient().get(url, headers={"User-Agent": "Mozilla/5.0"})
    items = r.json().get("items", [])
    return [{"name": i["item_basic"]["name"], "price": i["item_basic"]["price"]//100000,
             "sold": i["item_basic"]["sold"], "rating": i["item_basic"]["item_rating"]["rating_star"]}
            for i in items[:10]]

def ai_compare(items: list[dict]) -> str:
    client = anthropic.Anthropic()
    msg = client.messages.create(
        model="claude-sonnet-5",
        max_tokens=500,
        messages=[{"role": "user", "content":
            f"เปรียบเทียบสินค้า sustainable beauty เหล่านี้จาก Shopee: {items}\n"
            "เรียงตาม value-for-money สูงสุด พร้อมอธิบาย 1 บรรทัดต่อสินค้า ภาษาไทย"}]
    )
    return msg.content[0].text
```
